# Public release and internal archive paths

The current public Git root is Krylov_purification_v0.1/. Run its top-level scripts
from that directory. The preserved internal RC1 contains the complete manuscript
project, supplied input bundle, V3 authority and audit/certification archives.
The public package does not redistribute those complete originals.

V3 paths in CLAIM_SOURCE_MAP.md and historical provenance files are archive locators,
not relative links to public files. Historical ../Krylov_Private_Assets/ paths name
an optional separately provisioned private layout; that sibling was not supplied
or reconstructed by this assembly. Default public replay is self-contained.

scripts/paper_stage/ retains unchanged historical helper code. The top-level
wrappers reconstruct its root-relative layout in disposable directories. Use
scripts/build_paper.py and scripts/check_paper.py as documented. The legacy filename
paper/AI_ASSISTANCE_DISCLOSURE_TODO.md is retained because an unchanged historical
checker expects it; its content now records the approved disclosure.

RELEASE_AUDIT_CHANGES.md and provenance/RELEASE_REPAIR_MAP.json are unchanged
historical records of repairs already present in RC1. Their stage-local status
and path statements refer to that earlier package. Final current status and changes
are in RELEASE_NOTES.md, FINAL_FILE_CHANGES.md and FINAL_SCIENTIFIC_DELTA_AUDIT.md.
