# Frozen mathematical copy views

Files under `frozen/` are byte-identical selections from the original V3
mathematical archives, with origin and SHA-256 recorded in `provenance/COPY_MAP.json`.
Scripts retain their historical wording and expected results. Do not run them in
place: use the top-level disposable wrapper. No old source was edited for portability.

The directory is a curated view, not a complete original research tree. Internal
prompts, source extracts, historical logs, bytecode and failed candidates are
excluded. Exact original archives remain in the private sibling asset directory.
The name `clean_room_1r_search.py` belongs to a historical frozen verifier; replaying
it here is not a new clean-room reproduction or independent discovery.
